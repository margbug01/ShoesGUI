# Shoes

双击同目录的 ShoesGUI.exe，shoes.exe 保持放在旁边。

1. 在「代理」页添加或粘贴导入节点，点一下卡片就是选中。
2. 回到「仪表盘」点右上角「启动」（或打开「系统代理」开关），Shoes 接管系统代理；点「停止」恢复原来的设置。
3. 运行中也能随时换节点、换模式、编辑和导入，不用先停。换节点会断开现有连接，让浏览器立刻按新节点重连。

内核随 Shoes 一起常驻，只监听本机。没点「启动」时也能测速，也能把 127.0.0.1:10808 手动填给其他应用。改了节点、端口或内核路径，内核会在后台重启，大约 0.2 秒，系统代理保持接管。

出站模式：「规则」让局域网和国内（geosite/geoip cn）直连，其余走节点；「全局」除局域网外都走节点；「直连」全部不走节点。系统代理同时绕过 localhost、127.*、10.*、172.16–31.*、192.168.* 和不带点的本地名。

仪表盘：右上角是运行时长和启动/停止。「网速」是内核每秒报的上传、下载速度，曲线是最近 60 秒，实线下载、淡线上传；下面「本次上传/下载」从打开 Shoes 算起，经过内核的都算（直连的也算），内核重启也接着累加；「活动连接」「内核内存」仪表盘开着时每 2 秒刷新一次。「当前节点」可以测速、跳去「代理」页换节点。「网络接管」的系统代理开关和右上角按钮是同一件事；TUN 灰着，因为 shoes 内核在 Windows 上不支持。「出口 IP」经本地代理端口请求 ipwho.is（不通再试 ip-api.com），所以和浏览器走的是同一条分流，内核重启、换节点、换模式后会自动重查，右上角 ↻ 手动重查；只在仪表盘显示着的时候查。

测速：「代理」页右上角的闪电图标只测当前分组（搜索过滤后的那些），点开选一种。「真连接延迟」和 v2rayN 的同名功能一样：另起一个只用来测速的内核，每个节点一个本地入口，经入口用同一个连接连发两次 GET https://www.google.com/generate_204，取较小的那次（第二次已经握过手，基本是一个来回），两次都成功才算通，每个节点最多 5 秒。「TCPing」也和 v2rayN 一样，只计 TCP 连上服务器端口的时间，不走代理协议，通了不代表节点能用。卡片右键可以单测一个，仪表盘「当前节点」卡片的「测速」测当前节点（真连接）。两种结果共用一个显示位置，后测的覆盖先测的。500 ms 以内绿色（和 v2rayN 的分界一样），1000 ms 以内黄色，更慢或超时红色。测速不经过系统代理，不影响正在用的连接，没点「启动」也能测。

关闭窗口会缩到托盘。左键托盘图标打开窗口，右键可启动/停止、切模式、退出；图标绿色表示已接管系统代理。再次双击 ShoesGUI.exe 会把已经在跑的窗口叫出来。「设置」里可以选主题（跟随系统、浅色、深色），可以开「开机启动」（登录后在托盘待命）和「打开后自动启动」。

「日志」最新的在最上面，包含内核的警告和错误。内核意外退出时会自动恢复系统代理，并把退出原因写进日志。单条连接没正常收尾的报错（浏览器关了页面、换节点时断开旧连接、对方重置连接、TLS 断开没打招呼等）会翻成人话，同样的原因一分钟内合并成一行「连接异常 ×N：原因」；它们只影响那一条连接，网页能正常打开就不用管，成片出现并且网页打不开时再去测速换节点。右上角选「只看重要」可以把这类连接异常藏起来。内核日志写在 %APPDATA%/ShoesGUI 的临时文件里再读进来（内核写管道时会把中文系统错误变成问号），内核退出后文件自动删除。

支持 SOCKS5、HTTP、Shadowsocks AEAD/2022、Trojan、VLESS、VMess、AnyTLS，以及 TLS、Reality、Vision、WebSocket、XHTTP 和 VLESS 原生加密。

## 粘贴导入

在「代理」页点右上角剪贴板图标，粘贴内容后点「解析」，确认预览后点「导入」。支持单条或批量分享链接、Base64 订阅内容，以及返回上述内容的 HTTP/HTTPS 订阅地址。相同连接参数自动去重，失败项显示原因。订阅地址仅在导入时读取，不会定时更新。

「代理」页上方直接显示分组和数量，支持名称搜索。列表根据窗口宽度自动排成一列、两列或更多列；点击节点即可选中，悬停显示完整地址和右侧「⋯」菜单，编辑、删除也可通过右键菜单操作。快车、uzi 已从本机 v2rayN 导入，原数据未修改。

暂不支持 Clash YAML、gRPC、SS 插件、WebSocket Early Data、UDP/TUN，以及当前内核未提供的 Hysteria2/TUIC 出站连接；这些链接会提示不支持，不会静默降级。浏览器指纹名称会保留，但握手使用 Shoes 原生实现，不模拟 Chrome/Edge/Safari。

「运行中」表示已接管系统代理，不代表当前节点一定可达，可达不可达看测速。

节点配置保存在当前账户的 %APPDATA%/ShoesGUI，由 Windows DPAPI 加密。

## 开发

源码在 work/。在该目录运行：

```sh
go test ./...
go vet ./...
go build -trimpath -ldflags="-H windowsgui -s -w" -o ../outputs/ShoesGUI.exe .
```

UI 使用 MyGo，视觉组件参考 Mami。随附 Windows x64 内核基于 cfal/shoes 源码构建，版本 0.3.4，GUI 经它的 Clash API（随机端口加随机密钥，只在本机）切节点、切模式和测速。国内规则 work/rules/*.mrs 来自 MetaCubeX/meta-rules-dat（GPL-3.0），编进 GUI，首次运行写到 %APPDATA%/ShoesGUI/rules。第三方许可证在 licenses/。
