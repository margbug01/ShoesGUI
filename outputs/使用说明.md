# Shoes

双击同目录的 ShoesGUI.exe，shoes.exe 保持放在旁边。

1. 在「代理」页粘贴导入订阅或节点链接（也可以手动添加），点一下卡片就是选中。
2. 回到「仪表盘」点右上角「启动」，Shoes 接管系统代理；点「停止」恢复原来的设置。启动/停止只有这一个按钮。
3. 运行中也能随时换节点、换模式、编辑和导入，不用先停。换节点时默认断开现有连接，让浏览器立刻按新节点重连；不想打断下载和通话，可以在「设置 › 连接」关掉「切换节点时断开现有连接」，这样只有新连接走新节点。

内核随 Shoes 一起常驻，只监听本机。没点「启动」时也能测速，也能把 127.0.0.1:10808 手动填给其他应用。改了节点、端口或内核路径，内核会在后台重启，大约 0.2 秒，系统代理保持接管。

出站模式：「规则」让局域网和国内（geosite/geoip cn）直连，其余走节点；「全局」除局域网外都走节点；「直连」全部不走节点。系统代理同时绕过 localhost、127.*、10.*、172.16–31.*、192.168.* 和不带点的本地名。

仪表盘：右上角是运行时长和启动/停止；启动失败时那行红字可以点，直接跳到日志。「网速」是内核每秒报的上传、下载速度，曲线是最近 60 秒，实线下载、淡线上传；下面「本次上传/下载」从打开 Shoes 算起，经过内核的都算（直连的也算），内核重启也接着累加；「活动连接」「内核内存」仪表盘开着时每 2 秒刷新一次。「当前节点」可以测速，「切换节点」会跳到这个节点所在的分组并滚到它。「出口 IP」只在接管了系统代理时查：经本地代理端口请求 ipwho.is（不通再试 ip-api.com），和浏览器走的是同一条分流，内核重启、换节点、换模式后自动重查，右上角 ↻ 手动重查；没接管时这里直接写「未接管系统代理」，因为那时浏览器是直连的。TUN 没有放出来，shoes 内核在 Windows 上不支持。

测速：「代理」页右上角的闪电图标测当前分组（搜索过滤后的那些），点一下是「真连接延迟」，右键可以选「TCPing」。「真连接延迟」和 v2rayN 的同名功能一样：另起一个只用来测速的内核，每个节点一个本地入口，经入口用同一个连接连发两次 GET https://www.google.com/generate_204，取较小的那次（第二次已经握过手，基本是一个来回），两次都成功才算通，每个节点最多 5 秒。「TCPing」也和 v2rayN 一样，只计 TCP 连上服务器端口的时间，不走代理协议，通了不代表节点能用。卡片右键「测速 ›」可以单测一个，仪表盘「当前节点」卡片的「测速」测当前节点（真连接）。两种结果共用一个显示位置，后测的覆盖先测的，结果会存下来，重开 Shoes 还在。500 ms 以内绿色（和 v2rayN 的分界一样），1000 ms 以内黄色，更慢或超时红色。搜索框旁边选「按延迟」就按快慢排（没测的在后，超时的最后，测速进行中顺序先不动），「用最快的」直接切到这一组里测出来最快的节点。测速不经过系统代理，不影响正在用的连接，没点「启动」也能测。

关闭窗口会缩到托盘，第一次关的时候会弹一条系统通知说明。左键托盘图标打开窗口，右键可启动/停止、切节点（按分组，带上次测的延迟）、切模式、退出；图标绿色表示已接管系统代理。再次双击 ShoesGUI.exe 会把已经在跑的窗口叫出来。「设置」里的改动都是即时保存的：主题（跟随系统、浅色、深色）、「开机时启动 Shoes」（登录后在托盘待命，不会自己接管代理）、「打开时自动接管系统代理」（两个都开，登录后就直接可用）；本地端口按回车或点别处就保存，不合法会在下面说原因；内核路径在「高级」里，一般会自动找到，选了文件就保存。

「日志」最新的在最上面，包含内核的警告和错误，报错标红。可以搜索，可以选中一段复制，「复制」把当前显示的日志整个复制下来（方便发给别人看），「清空」清掉已有的。内核意外退出时会自动恢复系统代理，并把退出原因写进日志。单条连接没正常收尾的报错（浏览器关了页面、换节点时断开旧连接、对方重置连接、TLS 断开没打招呼等）会翻成人话，同样的原因一分钟内合并成一行「连接异常 ×N：原因」；它们只影响那一条连接，网页能正常打开就不用管，成片出现并且网页打不开时再去测速换节点。默认是「只看重要」，这类连接异常藏起来，顶上说一句藏了多少；切到「全部」能看到。内核日志写在 %APPDATA%/ShoesGUI 的临时文件里再读进来（内核写管道时会把中文系统错误变成问号），内核退出后文件自动删除。

提示和报错显示在窗口最下面一行，列表滚到哪都看得见，右边 ✕ 可以关掉；报错换页就清掉。

支持 SOCKS5、HTTP、Shadowsocks AEAD/2022、Trojan、VLESS、VMess、AnyTLS，以及 TLS、Reality、Vision、WebSocket、XHTTP 和 VLESS 原生加密。

## 粘贴导入

在「代理」页点右上角剪贴板图标（或在代理页按 Ctrl+V）。剪贴板里是节点链接、Base64 订阅内容或订阅地址时会自动填进来；别的内容（比如刚复制的密码）不会填，已经导入过的（刚导过的、已经绑了分组的订阅、链接全都在的）也不会再填。停下输入后自动识别，下面列出识别到的节点和没认出来的原因；选好「导入到」哪个分组，点「导入」才会真的导入。支持单条或批量分享链接、Base64 订阅内容，以及返回上述内容的 HTTP/HTTPS 订阅地址。相同连接参数自动去重。读订阅时 User-Agent 报的是 `v2rayN/7.13.8 ShoesGUI/0.1`：很多机场按 UA 决定回什么格式，不认得的就回 Clash YAML，报成 v2rayN 才回分享链接。粘贴进来的是一整份 Clash YAML 或 JSON 配置时会直接说不支持，不会把里面的 DNS、规则网址当成节点。

订阅地址导入到一个空分组（或新建的分组）时，这个分组就记住了订阅：分组上方显示订阅域名和「更新订阅」按钮。更新时同名节点就地换成新配置，新节点加到后面，订阅里已经没有的删掉；手动加进或挪进这个分组的节点不会被动。同一个订阅再粘贴导入一次也是更新，不会把换了密码的节点再加一份。要导去的分组里已经有别的节点时，会建议新建一个以订阅域名命名的分组，这样以后才能一键更新。订阅分组整份由订阅管，不跟别的分组去重：同一家机场以前手动导过一份，两组会各有一份，旧的那组不要了就右键删掉。订阅不会定时自动更新。

「代理」页上方是搜索框（Ctrl+F）、排序和「用最快的」，下面是分组和数量。分组按建的先后排，「未分组」在最后；右键分组可以重命名或删除（删除时可以选节点挪到未分组，还是连节点一起删）。列表根据窗口宽度自动排成一列、两列或更多列；点击节点即可选中，悬停显示完整地址，右侧「⋯」平时淡淡显示，点开或右键卡片是「编辑 / 测速 › / 移至分组 › / 删除」。删除的确认就出现在那张卡片上；删的是正在用的节点时，会在底部说明改用了哪个。手动添加节点（Ctrl+N）不会自动选中它，只有第一个节点会自动用上。编辑节点时密码和 UUID 默认遮住，旁边「显示」可以核对；公钥、Short ID 这些不是秘密，直接显示。快车、uzi 已从本机 v2rayN 导入，原数据未修改。

暂不支持 Clash YAML、gRPC、SS 插件、WebSocket Early Data、UDP/TUN，以及当前内核未提供的 Hysteria2/TUIC 出站连接；这些链接会提示不支持，不会静默降级。浏览器指纹名称会保留，但握手使用 Shoes 原生实现，不模拟 Chrome/Edge/Safari。

「运行中」表示已接管系统代理，不代表当前节点一定可达，可达不可达看测速。

节点配置保存在当前账户的 %APPDATA%/ShoesGUI，由 Windows DPAPI 加密。

## 开发

源码在 work/。在该目录运行：

```sh
go test ./...
go vet ./...
go build -trimpath -ldflags="-H windowsgui -s -w" -o ../outputs/ShoesGUI.exe .
```

UI 使用 MyGo，视觉组件参考 Mami。随附 Windows x64 内核基于 cfal/shoes 源码构建，版本 0.3.4，GUI 经它的 Clash API（随机端口加随机密钥，只在本机）切节点、切模式和测速。国内规则 work/rules/*.mrs 来自 MetaCubeX/meta-rules-dat（GPL-3.0），编进 GUI，首次运行写到 %APPDATA%/ShoesGUI/rules。第三方许可证在 licenses/。
