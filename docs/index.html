常见问题

MyShoes 和 ShoesGUI 是同一个项目吗？

是。MyShoes 是当前显示名，仓库和部分内部标识保留 ShoesGUI，以兼容旧版更新和配置。

安装后就有代理节点吗？

没有。需要自行提供合法可用的节点配置或订阅，软件不提供代理服务。

支持哪些平台？

Windows 10/11 和 Apple Silicon Mac。下载时查看当前发布版本的平台说明。

同一作者的其他 MyGo 应用： Mami · MySpotify · MyShoes · Candle
