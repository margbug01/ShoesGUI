MyShoes
Native GUI for the shoes proxy core

A native Windows and macOS proxy client for the shoes core, with subscriptions, latency tests, rule-based routing and tray support. Formerly ShoesGUI.

Download latest releaseDocumentation and source

Windows / macOS · GPL-3.0

Features

Subscriptions and nodes

Import your configurations and subscriptions, update groups and test latency.

System proxy and routing

Manage the system proxy and choose direct or proxied traffic with routing rules.

Native desktop interface

Built with Go and MyGo, bundles the shoes core and stays in the tray.

Install and get started

Choose the release asset matching your operating system and processor. Follow the repository setup instructions and read permissions, configuration requirements and limitations before use.

Frequently asked questions

Is MyShoes the same as ShoesGUI?

Yes. MyShoes is the current display name; the repository and some internal identifiers remain ShoesGUI for compatibility.

Are proxy servers included?

No. Bring your own legally usable server configuration or subscription. This app does not provide a proxy service.

Which platforms are supported?

Windows 10/11 and Apple Silicon Macs. Check the current release notes for platform details.
